# 宠物行为识别 · 训练与测试数据集资源清单

> 整理日期：2026-09-01。以下资源均为公开可获取的真实宠物视频/图像数据集，
> 可用于本项目的测试演示（画面有真实猫狗）以及后续 YOLOv8 微调训练。

---

## 一、已内置到本项目的测试素材

### 1. 真实猫行为视频（已下载 ✅）

- **来源**：HuggingFace 数据集 [`Raullen/petvlm-data`](https://huggingface.co/datasets/Raullen/petvlm-data)
- **内容**：175+ 个真实宠物（猫）行为视频片段，分为两大类：
  - `calm_*`：安静/正常行为（睡觉、趴卧、安静休息）
  - `naughty_*`：异常行为（爬家具、抓挠、偷食物、推倒东西）
- **位置**：`data/videos/pets/`（每个片段约 0.1~0.4 MB，已按 YOLO 检测稳定性筛选）
- **用途**：直接用 `python main.py --video data/videos/pets_real.mp4` 测试完整链路
  （YOLO 检测 → 行为识别 → 异常报警）
- **许可**：数据集基于 YouTube 宠物合集视频裁剪（YOLOv5 + 30% padding）

### 2. 真实狗行为视频（已下载 ✅）⭐ 带行为标注

- **来源**：HuggingFace 数据集 [`fishchen/dog-behavior-dataset`](https://huggingface.co/datasets/fishchen/dog-behavior-dataset)
- **内容**：1000 个真实狗行为视频（共约 8 GB，30 fps，每段 6~10 秒），
  **自带行为标注**（`metadata.jsonl`：行为标签 + 时间段 + 文字描述）
- **5 类行为**：
  | 行为 | 视频数 | 对应本项目行为 |
  |------|--------|----------------|
  | eating（进食） | 269 | eating（进食识别）⭐ |
  | toy（玩玩具） | 259 | active（活跃） |
  | yawn（打哈欠） | 301 | resting（困倦休息） |
  | pooping（排便） | 269 | anomaly（异常报警） |
  | rope（咬绳拔河） | 119 | active（活跃） |
- **位置**：`data/videos/dogs/`（每类精选 5 段）+ 拼接好的 `data/videos/dog_real.mp4`
- **用途**：`python main.py --video data/videos/dog_real.mp4` 测试狗的行为识别链路
- **完整数据集获取**（用于微调训练）：
  ```bash
  # 国内镜像（推荐）
  git clone https://hf-mirror.com/datasets/fishchen/dog-behavior-dataset
  ```

### 3. 合成演示视频（原有）

- `data/videos/demo.mp4`：程序生成的合成视频，用于无网络环境的基础演示
- ⚠️ 合成矩形不会被 YOLO 识别为猫/狗，仅验证 GUI 与监控链路

## 二、推荐的公开数据集（用于微调训练）

### 1. 狗行为目标检测数据集（YOLO 格式）⭐ 最适合本项目微调

- **内容**：近 3000 张高清图像，6 种行为类别（吠叫、进食、趴卧、奔跑、端坐、站立）
- **格式**：YOLO 格式标注，直接适配 YOLOv5/v8 训练
- **获取**：百度网盘 `https://pan.baidu.com/s/11hgTiAdeEZ7Hbu6vwHCcAg?pwd=tn2a`（提取码 tn2a）
- **介绍**：[阿里云开发者社区文章](https://developer.aliyun.com/article/1755883)
- **用法**：解压后执行 `python main.py --train --data <解压目录> --epochs 50`

### 2. Real-World Dog Behavior Videos（Kaggle）

- **地址**：https://www.kaggle.com/datasets/umuttuygurr/videosdog
- **内容**：64 个室内俯视（顶视角）长视频（共 1.42 GB），单只狗的日常行为：
  睡觉/休息、屋内走动、站立转身、与食盆互动
- **许可**：CC0 公共领域
- **适用**：休息/活动二分类、时间序列行为分析、无监督方法
- **注意**：无人工标注，需自行生成标签；需注册 Kaggle 账号下载

### 3. DogCentric Activity Dataset（九州大学）

- **地址**：https://robotics.ait.kyushu-u.ac.jp/yumi/db/first_dog.html
- **内容**：狗第一视角（背部绑 GoPro）行为视频，10 类行为：
  玩球、等车经过、喝水、喂食、左转头、右转头、被抚摸、抖毛、嗅闻、行走
- **规格**：320×240 分辨率，48 fps，已按行为做时间分段
- **下载**：匿名 FTP `ftp://robotics-ftp.ait.kyushu-u.ac.jp`（dogcentric 目录）
- **引用**：Iwashita et al., ICPR 2014

### 4. Stereo Ego-Motion Dataset（弗莱堡大学）

- **地址**：https://lmb.informatik.uni-freiburg.de/resources/datasets/StereoEgomotion.en.html
- **内容**：494 个全高清双目视频，4 类（car/cat/chair/dog），
  其中猫（5.6 GB）与狗（4.8 GB）视频含丰富的关节运动
- **许可**：仅限研究用途，禁止商用
- **下载**：页面直链（Cats.zip / Dogs.zip）

### 5. EgoPet（学术数据集）

- **论文**：https://arxiv.org/abs/2404.09991
- **内容**：848+ 小时的宠物第一视角视频（狗、猫、鹰、龟等）
- **适用**：大规模预训练、交互预测研究

### 6. Inertial Data for Dog Behaviour（Kaggle）

- **地址**：https://www.kaggle.com/datasets/benjamingray44/inertial-data-for-dog-behaviour-classification
- **内容**：项圈/胸背带 IMU 传感器数据（100 Hz 加速度计 + 陀螺仪），
  7 类行为（奔跑、趴卧、坐、嗅闻、站立、小跑、行走）
- **许可**：CC BY 4.0
- **适用**：非视觉模态的多模态行为识别扩展（本项目暂不涉及）

## 三、训练流程提示

1. 数据集准备成 YOLO 格式（`images/` + `labels/`，或已带 data.yaml）
2. 执行微调：
   ```bash
   python main.py --train --data <数据集目录> --epochs 50
   ```
3. 训练完成后的 `best.pt` 会自动复制到 `data/models/`，重启监控即生效
4. 详细参数说明见 `docs/02_系统设计.md` 与 `docs/04_用户手册.md`
