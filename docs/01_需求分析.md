# 01 · 需求分析

## 1.1 项目背景

随着生活水平提升与城市化进程加快，家庭饲养宠物（尤其是猫狗）的比例持续增长。但工作繁忙的宠物主难以为宠物提供全天候陪伴，宠物的异常行为（如长时间静止、拒食、突发抽搐）若不能被及时发现，可能引发严重健康甚至生命危险。

另一方面，现有的家用监控摄像头仅提供"被动录像"功能，无法对画面内容进行**智能理解与主动预警**。随着 YOLO 等实时目标检测模型的成熟与边缘设备算力的提升，将"目标检测 + 行为理解 + 报警推送"集成到一个桌面级应用成为可能。

## 1.2 选题依据

任务书所列 10 个选题均集中于工业监控领域。本项目自选 **"宠物行为识别监测系统"**，契合任务书要求（机器视觉 / Python / OpenCV / 数据库），同时具备：

- 演示门槛低（家庭场景）
- 技术栈完全复用任务书要求
- 可扩展为商用产品的潜力

## 1.3 项目目标

开发一款桌面应用，对宠物（猫/狗）实时视频流进行：

1. **检测** — 自动识别画面中的猫和狗，给出位置与置信度；
3. **跟踪** — 跨帧维持同一只宠物的稳定 ID；
4. **行为识别** — 识别 5 类典型行为：`休息 / 活动 / 进食 / 饮水 / 异常`；
5. **记录** — 把每帧的检测结果与每段行为持续时长存入 SQLite；
6. **报警** — 对异常行为（如疑似晕厥/抽搐）触发声光报警；
7. **可视化** — PyQt5 GUI 实时显示画面、表格与统计；
8. **可配置** — 用户可在 GUI 内调整检测置信度、行为阈值、ROI 区域。

| 编号 | 描述 | 验收标准 |

| FR-08 | GUI 实时显示 | 主窗口视频区域 ≥ 1 FPS |

## 1.7 约束与假设

| 编号 | 描述 |
| --- | --- |
| AS-01 | 训练环境未提供 GPU，使用 CPU 推理（yolov8n，imgsz=640） |
| AS-02 | 用户摄像机视野内只有 1~2 只宠物 |
| AS-03 | 食物/水盆位置相对固定，通过 GUI 设置 ROI |
| AS-04 | "异常"行为通过长时间静止 + 微抖动启发式判定，可能存在误报；不替代兽医诊断 |

## 1.8 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| CPU 推理慢 | FPS 不足 | 提供 yolov8n/s/m 切换；可减小 imgsz |
| YOLOv8 把猫/狗混淆 | 检测错误 | 仅使用高置信度阈值的检测结果 |
| 宠物被遮挡 | 跟踪中断 | 跟踪器容忍 15 帧丢失 |
| 异常误报 | 用户疲劳 | 报警冷却 30s；可在 GUI 关闭声音 |
| 数据库膨胀 | 性能下降 | 自动清理 30 天前数据（`purge_older_than`） |

## 1.9 验收方式

- 报告交付：`docs/` 5 篇文档完整
