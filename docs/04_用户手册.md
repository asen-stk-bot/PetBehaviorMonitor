# 04 · 用户手册

## 4.1 安装

### 4.1.1 系统要求

- Windows 10/11（推荐）、macOS 12+、Ubuntu 22.04+
- Python 3.10 或更高版本
- 至少 200 MB 可用磁盘（用于 YOLOv8 模型与数据库）

### 4.1.2 步骤

```bash
# 1. 进入项目目录
cd PetBehaviorMonitor

# 2. （推荐）创建虚拟环境
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux/macOS

# 3. 安装依赖
pip install -r requirements.txt

# 4. 启动
python main.py
```

> 首次运行会自动下载 `yolov8n.pt`（约 6 MB），需联网。

## 4.2 启动选项

```bash
python main.py                  # 默认摄像头
python main.py --demo           # 使用内置演示视频
python main.py --video a.mp4    # 指定视频
python main.py --camera 1       # 切换到第 2 个摄像头
python main.py --tests          # 运行单元测试
python main.py --gen-demo       # 重新生成演示视频
python main.py --report         # 生成行为分析报告（HTML + CSV）
python main.py --report --date 2026-09-01   # 指定统计日期
python main.py --train --data path/to/dataset --epochs 50   # 微调模型
python main.py --log DEBUG      # 调试日志
```

### 4.3.1 控制标签

| 控件 | 作用 |
| --- | --- |
| 视频源下拉 | 选择 0/1/2 号摄像头，或在文本框填写视频文件路径 |
| 浏览… | 弹出文件对话框选择视频 |
| 开始监控 / 停止监控 | 启动 / 停止后台读帧线程 |
| 检测置信度 | YOLO 置信度阈值（0.05–0.95） |
| 静止阈值 | 判定为"休息"的位移上限（像素） |
| 活跃阈值 | 判定为"活动"的位移下限（像素/帧） |
| 异常判定时长 | 静止多久触发异常报警（秒） |
| 进食 ROI / 饮水 ROI | 4 个浮点数，逗号分隔，归一化 0–1 |
| 应用 ROI | 把 ROI 写入配置并叠加到视频上 |

### 4.3.2 事件标签

显示最近 200 条事件，列：时间 / ID / 物种 / 行为 / 置信度 / 来源。

### 4.3.3 报警标签

显示所有报警，列：时间 / 级别 / 消息 / 是否已读。
"全部标记已读" 一键清除未读状态。

### 4.3.4 统计标签

显示每种行为的累计时长（来自 `behavior_summary` 表）以及彩色柱状图（纯 QPainter 绘制，无需额外依赖）。点击"生成每日汇总"可把当天数据聚合写入 `daily_stats` 表。

### 4.3.5 快照标签

以缩略图网格展示报警快照（`data/snapshots/`），异常/进食/饮水报警触发时自动截图。点击"打开快照目录"可在资源管理器中查看原图。

## 4.4 报告导出

**方式一：GUI 菜单** —— 点击菜单栏「报告(R)」→「生成 HTML 报告…」或「导出事件 CSV…」。

**方式二：命令行**

```bash
python main.py --report                 # 生成当天报告
python main.py --report --date 2026-09-01
```

生成的 HTML 报告（`data/reports/report_YYYY-MM-DD.html`）是**自包含**的，含行为时长分布图、24 小时分时活动图、最近报警表、快照画廊，双击即可用浏览器查看，适合直接放进答辩材料或发给老师。

## 4.4 典型操作流程

### 4.4.1 用演示视频快速体验

```bash
python main.py --demo
```

应用启动后会自动开始播放演示视频。视频中合成矩形模拟猫和狗（在画面上清晰标注 CAT / DOG 字样），系统在右下方表格持续追加事件。

> **注意**：YOLO 不会把合成矩形识别为"猫"或"狗"，所以 detections=0。要看到真实检测，需使用包含真实猫狗的视频或对准真实宠物的摄像头。

### 4.4.2 用真实宠物视频测试

1. 把 mp4 文件放到 `data/videos/`
2. 启动 GUI：`python main.py`
3. 在"控制"标签点击"浏览…"，选择该 mp4
4. 点击"开始监控"

预期结果：视频中猫/狗出现彩色矩形框，框上方有 "cat#1 resting 0.92" 这样的文字。

### 4.4.3 调整 ROI

1. 观察实际画面，估算食物盆和水盆的归一化坐标
   - 左下角 = (0, 0)，右上角 = (1, 1)
2. 在"控制"标签修改"进食 ROI"和"饮水 ROI"
3. 点击"应用 ROI"
4. 画面上会显示淡色框确认区域

### 4.4.4 关闭蜂鸣

打开 `src/pet_monitor/config.py`，把 `AlertConfig.enable_sound` 改为 `False`。

## 4.5 模型微调（可选）

系统默认使用 COCO 预训练的 `yolov8n.pt`（识别猫=15、狗=16）。如需针对特定品种/场景提升精度：

```bash
# 1. 准备 YOLO 格式数据集（目录结构）：
#    dataset/images/train/*.jpg   dataset/labels/train/*.txt
#    dataset/images/val/*.jpg     dataset/labels/val/*.txt
#    （标签每行：class x_center y_center w h，归一化，class 0=cat 1=dog）

# 2. 检查数据集（不训练）
python main.py --train --data path/to/dataset --dry-run

# 3. 开始微调
python main.py --train --data path/to/dataset --epochs 50
```

训练完成后 `best.pt` 会复制到 `data/models/`，运行监测时指定：

```bash
# Windows
set PET_MODEL=best.pt && python main.py
# 或直接在 config.py 中改 DetectorConfig.model_name
```

## 4.6 数据存储位置

| 类型 | 路径 |
| --- | --- |
| 数据库 | `data/pet_monitor.db` |
| YOLO 模型 | `data/models/yolov8n.pt`（微调后 `best.pt`） |
| 演示视频 | `data/videos/demo.mp4` |
| 报警快照 | `data/snapshots/*.jpg` |
| 报告/CSV | `data/reports/` |
| 配置持久化 | `data/config.json` |

如需备份，把整个 `data/` 目录拷贝即可。

## 4.7 常见问题

| 问题 | 解决 |
| --- | --- |
| 启动报错 "No module named PyQt5" | `pip install PyQt5` |
| 摄像头打不开 | 检查系统权限；尝试 `--camera 1` |
| FPS 太低 | 关闭其他程序；或换 `yolov8n` → 更小模型 |
| 中文乱码 | 报告/CSV 已用 UTF-8 编码；若终端乱码，设置 Windows 区域为 UTF-8 |
| 数据库锁死 | 关闭程序后删除 `data/pet_monitor.db-journal` |
