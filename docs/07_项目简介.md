## 二、项目简介

**宠物行为识别监测系统** 是一款基于计算机视觉的桌面应用，面向养宠家庭场景，通过摄像头实时识别宠物的行为状态（活动 / 休息 / 进食 / 饮水等），并在出现异常行为时自动触发报警与快照记录，帮助主人不在家时也能掌握宠物动态。

系统以 **YOLOv8** 目标检测为核心，结合 **OpenCV** 视频处理与 **PyQt5** 图形界面，构建了「检测 → 跟踪 → 行为识别 → 异常报警 → 数据存储 → 报告生成」的完整链路，是一个覆盖需求分析、系统设计、编码实现、测试验证全流程的软件工程综合训练项目。

## 四、核心功能

1. **实时目标检测**：YOLOv8 识别画面中的猫 / 狗，标注检测框与置信度
2. **多目标跟踪**：基于 IoU 的轻量跟踪器，为每个宠物维持稳定 ID
3. **行为识别**：根据轨迹位置、运动幅度、停留时长识别「活动 / 休息 / 进食 / 饮水 / 未知」五类行为
4. **异常报警**：检测到异常行为（如长时间剧烈活动）触发报警，支持冷却时间避免重复
5. **快照截图**：报警时自动保存现场画面到数据库
6. **数据统计**：行为事件入库，支持按时间段查询、行为分布统计
7. **报告生成**：一键生成 HTML 行为分析报告（含统计图表）
8. **参数可调**：GUI 内可调节检测置信度、IoU 阈值、报警冷却时间、ROI 区域
9. **真实测试视频**：内置真实宠物行为测试视频（猫 + 狗），无需摄像头即可演示

## 六、运行方式

```bash
# 1. 克隆仓库
git clone https://github.com/asen-stk-bot/PetBehaviorMonitor.git
cd PetBehaviorMonitor

# 2. 创建虚拟环境并安装依赖
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

# 3. 启动 GUI（推荐）
python main.py --video data/videos/pets_real.mp4

# 4. 跑测试
python main.py --tests
```
